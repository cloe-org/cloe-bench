# :vs: cloe-bench
### *Scientific validation of cloelib and cloelike 3x2pt observables*
Compare 2pt statistics and cosmological inference results with other pipelines: CosmoSIS (harmonic and configuration space) and CosmoPipe(COSEBIs)

---

## :on: What can I find in *cloe-bench*?
**cloe-bench** is a repository dedicated to validate theoretical predictions and inference products for:
- Harmonic Space angular spectra against CosmoSIS
- Real Space 2PT correlation functions against CosmoSIS
-  Real Space COSEBIs modes agains CosmoPpipe
